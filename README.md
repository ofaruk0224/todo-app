# Todo App

JavaScript ile geliştirilmiş görev takip uygulaması.

**Canlı demo:** https://ofaruk0224.github.io/todo-app/

## Özellikler
- Görev ekleme, silme, düzenleme ve tamamlama
- Öncelik ve tarih belirleme, gecikmiş görevleri işaretleme
- Tümü / Bekleyen / Tamamlanan filtreleri
- Koyu ve açık tema
- Verilerin `localStorage` ile saklanması
- Mobil uyumlu tasarım

## Kullanılan teknolojiler
HTML, CSS, JavaScript
